# 💼 Personal Portfolio Website

A personal portfolio website built to showcase my skills, projects, and learning journey as a BCA student. The website provides an overview of my technical abilities, projects, and professional interests.

## ✨ Features

- **About Me:** Introduction and career goals.
- **Skills:** Overview of technical skills and technologies.
- **Projects:** Showcase of personal and academic projects.
- **Contact:** Contact information and professional links.
- **Responsive Design:** Layout designed to work across different screen sizes.
- **Clean UI:** Simple and user-friendly interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (if implemented)

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.
4. Explore the portfolio website in your browser.
